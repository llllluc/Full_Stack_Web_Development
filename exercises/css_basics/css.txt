There are 3 ways in which we can add CSS in to HTML:
    *Inline
        <tag style="css" />
         Example: exercises/css_basics/css_inline.html
         It is used to apply the style as the name says, inline

    *Internal
        <style>css</style>
        Example: exercises/css_basics/css_internal.html
        It is used to apply the style in one HTML file, this can't be used for multiple pages websites
    *External
        <link herf="style.css"/>
        Example: exercises/css_basics/css_external.html  (html file)
        Example: exercises/css_basics/styles.css  (css file)
        This is used for multiple pages websites, it can be linked to multiple pages
