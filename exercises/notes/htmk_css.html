HTML and CSS



HTML

                            
                                1. <!DOCTYPE HTML> is a type declaration, it helps the browsers to display the page correctly.
                            
                        
                            
                                2. The HTML document itself begin with <html> and ends with </html>. Whitin this we also 
                                declare the language in the begining <html lang=en>
                            
                        
                            
                                3. The visible part of the html document is between <body> and </body>.In this we can have:
                                    *Hedings: -h1
                                              -h2
                                              -h3
                                              -and so on...till h6
                                    Those can be used like this <h1>The Title</h1>
                                    *Paragraphs. <p>This is a paragraph.</p>
                                    *Links. <a herf="https://www.google.com">This is a link</a>
                                    *Images. <img src="../../assets/images/image01.png" />
                            
                        
                            
                                3. Head of the html is between <head> and </head>.This where we put informations about
                                the page:
                                    *The title, that appears on the tab in the browser. Which can be set like this <title>HTML 
                                    and CSS</title>
                                    *The type of charset used on the page. Most common is: <meta charset="UTF-8">
                                    *Link to a css file. EX: <link rel="stylesheet" herf="./location_folder/css_style_for_page.css">
                                    *Whit the line from above we can also add an icon, by simply changeing the rel="icon" and the
                                    herf="location/icon.png"

CSS

                            
                                Cascading Style Sheets is used to format the layout of a webpage. Whit CSS, we can control the colors, 
                                font, the size of the text, the spacing between elements, how elements are positioned and laid out,
                                what background-colors or images are used, different displays for different devices and screen sizes,
                                and so on...
                                There are 3 ways to add css to a HTML document:
                            
                        
                            
                                1.INLINE -by using style attribute inside the elements
                                    Ex: <h1 style="color:blue;">A blue heading</h1>
                            
                        
                            
                                2.INTERNAL by using <style> element in the <head> section
                                    Ex: 
                                    <!DOCTYPE html>
                                        <html>
                                            <head>
                                                <style>
                                                    body {background-color: pink;}
                                                    h1 {color: yellow;}
                                                    p {color: red;}
                                                </style>
                                            </head>

                                            <body>

                                                <h1>This is a heading</h1>
                                                <p>This is a paragraph</p>

                                            </body>
                                    <html>

                            
                        
                            
                                3.EXTERNAL by using <link> element to link an external css file
                                    Ex:
                                    HTML
                                    <!DOCTYPE html>
                                        <html>
                                            <head>
                                                <link rel="stylesheet" herf="/locationfolder/css_for_index.css">
                                            </head>

                                            <body>

                                                <h1>This is a heading</h1>
                                                <p>This is a paragraph</p>

                                            </body>
                                    <html>

                                    CSS
                                    body {background-color: pink;}
                                    h1 {color: yellow;}
                                    p {color: red;}
